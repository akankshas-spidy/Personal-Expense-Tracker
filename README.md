# Personal Expense Tracker

## Project Description
Personal Expense Tracker is a Python-based application that helps users manage and track their daily expenses.

## Features
- Add new expenses
- View all expenses
- Categorize expenses
- Calculate total spending
- Store expense records in CSV format

## Technologies Used
- Python
- CSV
- OS Module

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run:

   python expense_tracker.py
